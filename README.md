# GSPY Repository

This repository contains resources for the development of the **GSpy** Python package ecosystem.  
The folder structure is organized as follows:

```bash
GSPY/
├── documentation/          # Documentation related to GSpy package development
├── gspy-package/           # Official source code for the gspy-egse Python package (Python 3.13, Qt6)
├── gspy-spw-dummy-plugin/  # Demo plugin for SpaceWire, based on gspy-classic (Python 3.11, Qt5)
├── gspynext-package/       # Prototype package for GSpy-Next (not actively maintained)
└── logs/                   # Log files generated by gspy-package
```

## Branches

This repository contains multiple branches for ongoing development.  
The **`development`** branch serves as the stable version of the `gspy-package`.  

To test the package, please clone the repository, install the `gspy-package`, and run it.
